# DownloadManagerFS Releases

Official releases and portable launchers for **Android**, **Linux**, and **Windows**.

---

## 📱 Android (Mobile App)

**File:** [`DownloadManagerFS-v1.2.1.apk`](DownloadManagerFS-v1.2.1.apk)

### How to Install:
1. Transfer the `.apk` file to your Android phone (or download directly from GitHub Releases).
2. Tap the APK file to install (enable "Install from Unknown Sources" if prompted).
3. Open **Download Manager FS** and start downloading!

---

## 🐧 Linux (Standalone Executable)

**File:** [`DownloadManagerFS-Linux`](DownloadManagerFS-Linux)

### How to Run:
```bash
# Make executable
chmod +x DownloadManagerFS-Linux

# Run the app
./DownloadManagerFS-Linux
```
*The app will start the high-speed engine and automatically open your default browser to `http://localhost:5000`.*

---

## 🪟 Windows (.bat / .exe)

**Files:**
- **Quick Launcher:** [`DownloadManagerFS-Windows.bat`](DownloadManagerFS-Windows.bat)
- **PowerShell Runner:** [`DownloadManagerFS-Windows.ps1`](DownloadManagerFS-Windows.ps1)
- **Direct Release:** Available under the [GitHub Releases tab](../../releases/tag/v1.2.1).

### How to Run:
1. Double-click **`DownloadManagerFS-Windows.bat`**.
2. It will automatically check Python & `yt-dlp` dependencies and open `http://localhost:5000` in your default browser.
3. Videos will be downloaded to your `Downloads\DownloadManagerFS` folder.
